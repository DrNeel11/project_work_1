Where exactly could the novelty be?

Established building blocks

Coverage NBV, Bayesian memory, deterioration filtering, maintenance value of information, nuisance inference, and nonmyopic planning already exist. A staircase of features does not make them novel.

Candidate contribution

A persistent joint belief proposes a small set of physically feasible, complementary view pairs that preserve maintenance decision quality while reducing expensive belief-space evaluation.

The implementation uses a covariance-based proxy for reduction in future-risk variance, followed by exact decision-loss evaluation. That proxy is a standard linear-estimation construction. Its use here is a candidate design, not a new theorem.

Why individual view scores can fail: a minimal witness

Let damage D and artifact N be independent fair bits. A observes D XOR N; B observes N. Each alone contains zero information about D. Together they determine D exactly. With defer loss 100D and repair cost 20, no inspection costs 20 in expectation; the two noiseless views cost 10 + 2c. For 0 < c < 5, a myopic planner stops while a two-view planner acquires. This is a mechanism proof, not a claim of inventing information synergy.

Memory A: P(D=0,N=0)=P(D=1,N=1)=1/2 Memory B: P(D=0,N=1)=P(D=1,N=0)=1/2 Both: P(D=1)=P(N=1)=1/2 Observe N=1 → Memory A: repair; Memory B: defer. Marginal-only memory cannot reproduce both correct decisions.
